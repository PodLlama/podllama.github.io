Zero-Trust Security Architecture

Strict Data Privacy & Sandboxed Execution

When an autonomous AI agent or coding assistant suggests terminal commands or refactors source files, isolation is not optional. PodLlama implements true defense-in-depth security.

Rootless Podman User Namespace Mapping

All services and CLI agents run under unprivileged rootless Podman containers using --userns=keep-id. The internal container process matches your exact host UID and GID without granting root privileges, completely preventing privilege escalation vulnerabilities.

SELinux Volume Boundary Isolation

Workspace folders and model caches are mounted with strict SELinux volume relabeling (:z for shared writable workspace and :ro,z for read-only model weights). This prevents agent processes from escaping the mounted project directory to inspect host SSH keys or private credentials.

Internal Container Microservices Network

Only the LiteLLM Proxy on port 4000 is published to host 127.0.0.1. The chat model swapper (port 8080) and autocomplete engine (port 8081) remain sealed inside the internal Podman bridge network (containers_default), preventing unauthorized network exposure.

100% Air-Gapped & Zero Outbound Telemetry

The model server and proxy run without requiring internet connectivity after model download. No telemetry, usage tracking, prompt logs, or metric pings are sent to any external server. Compliance with strict enterprise NDA, HIPAA, and GDPR requirements is guaranteed.

Comprehensive Capabilities

Unique Server & Client Features

Built from the ground up for developer productivity, universal hardware adaptability, and zero-leakage security.

Universal Hardware & OS Adaptability

Turns any PC or laptop into an LLM workstation. Powered by a custom build of llama.cpp with Vulkan compute shaders, it enables the host computer to use Vulkan to offload transformer layers to Intel Arc, AMD Radeon, or NVIDIA GPUs via /dev/dri, or seamlessly fallback to multi-threaded CPU inference. Runs across Linux, macOS, and Windows on Podman (preferred) or Docker.

Dual-Model Concurrency

Dedicated chat (port 8080) and autocomplete (port 8081) services operate concurrently. Fast inline ghost-text suggestions continue rendering even while a complex multi-turn reasoning stream is in progress.

Idle Auto-Stop (0 MB VRAM)

The chat swapper supervisor tracks idle time and automatically terminates the backend model process after inactivity (default 600s). Frees 100% of LLM VRAM and RAM until the next incoming prompt cold-starts it seamlessly.

Multithreaded Model Auto-Swapper

Powered by chat_swapper.py on port 8080. Automatically unloads and hot-swaps between general chat (podllama-chat) and deep reasoning (podllama-thinking) on the fly without restarting container stacks.

Multi-Session Parallel Streaming

The companion VS Code extension allows launching multiple generation streams across separate conversations simultaneously. Background streams continue accumulating tokens in memory without aborting.

Session Markdown Export & Attachments

Easily export full chat conversations as Markdown or insert them directly into active editor files. Attach any workspace source file directly into prompts with a single click.

Sandboxed Workspace Agents

Includes ready-to-run container wrappers for official pi.dev and Oh My Pi (omp.sh) terminal agents, allowing AI to safely execute commands inside your project.

Quick Start Guide

Get Running in 6 Simple Steps

All configuration and orchestration are managed through automated Makefile targets and rootless Podman containers.

1

Verify System Infrastructure & GPU Acceleration

Checks for Podman, Python 3, PyYAML, curl, and Vulkan GPU hardware DRI drivers (/dev/dri):

make check-infra
2

Download LLM Model Weights

Download active models (0.5B autocomplete, 7B chat, and 7B reasoning — ~9.8 GB total) and verify SHA256 integrity:

make download-active-models && make check-checksum
3

Build Container Images (Custom llama.cpp Vulkan Build)

Builds multi-stage container images featuring a custom build of llama.cpp compiled with native Vulkan acceleration for the host computer to use Vulkan GPU compute, LiteLLM proxy router, and workspace CLI agent images:

make build
4

Build & Install PodLlama Code VS Code Extension

Compiles the TypeScript extension, generates the .vsix package, and installs it directly into VS Code:

make build-extension && make install-extension
5

Launch Container Services Stack

Starts Chat Server (8080), Autocomplete (8081), and LiteLLM Proxy on host port 4000 via Podman Compose:

make service-up && make service-status
6

Verify Endpoints with Automated Smoke Tests

Runs live 12-stage endpoint verification smoke tests validating chat, reasoning, autocomplete, persona injection, streaming SSE, and idle auto-stop recovery:

make smoke-test
